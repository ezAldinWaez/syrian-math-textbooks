# كتب الرياضيات السورية

كتب الرياضيات المدرسية السورية بصيغة Markdown، مهيّأة للاستخدام المباشر مع النماذج اللغوية والوكلاء. تأتي المعادلات بصيغة LaTeX، وترتبط الرسوم بمواضعها في النص. تضم المجموعة حالياً جزأي كتاب الرياضيات للصف الثاني عشر (2021–2022).

## القراءة والتنزيل

نزّل حزمة الجزء المطلوب وأرفقها بالنموذج أو الوكيل. تبدأ القراءة من `INDEX.md` لتحديد الوحدة ونطاق أسطرها في `book.md`. إذا كانت الأداة تتطلب ملفات منفصلة، فكّ الحزمة وأرفق النص والفهرس ومجلد `images/` معاً. [صفحة الإصدار](https://github.com/ezAldinWaez/syrian-math-textbooks/releases/tag/books)

## المساهمة

يمكنك مراجعة جودة تفريغ الكتب الحالية أو إضافة كتاب. تجد خطوات المراجعة والتفريغ في [دليل المساهمة](CONTRIBUTING.md).

## الترخيص

يسري ترخيص MIT على وثائق المستودع الأصلية وإعدادات الأتمتة. تبقى حقوق الكتب ونصوصها المفرّغة ورسومها وملفاتها الأصلية، وحقوق مرجع التفريغ المرفق، لأصحابها. [نص الترخيص](LICENSE)

## النشر

يُنشئ سير العمل إصدار `books` عند النشر الأول ويحدّث وصفه وحزمه عند وصول تغييرات الكتب إلى `main`. ويمكن تشغيله يدوياً من تبويب **Actions**. [سير عمل الإصدار](.github/workflows/release.yml)
